# 问题与方法

## 演练票污染真实直播票（已修复并回归）

现象：早期只按当前连接状态禁用演练，连接前的虚拟票可能继续留在同一个真实章节；断线重连时演练又可能开放。

定位：父代理评审指出状态不是章节身份。新增用例先演练投票，再输入真实来源消息，确认旧实现错误接受。真实与演练共享了同一个票表，且切连接未要求关闭章节。

修复：`src/story.mjs` 将来源绑定每个章节，在引擎入口拒绝不匹配消息；`server.mjs` 在开章时决定来源、切连接前要求关章；重连保留live身份；历史与overlay显示来源。空票章节可由New chapter关闭，避免无法切模式。

验证：新增来源隔离和空章节恢复用例先失败后通过，且原有票数/HTTP测试通过。适用边界：这验证内部消息来源隔离，真实Twitch认证与外部消息投递仍需账户测试。

## 本地HTTP测试EACCES（环境限制已识别）

现象：服务器能启动，但受限进程访问127.0.0.1返回EACCES，2个HTTP集成测试失败。

定位：异常发生在TCP连接，单元测试通过；相同代码在允许本地网络的执行环境重跑全部通过。

处理：仅对本地预览和集成检查申请环境权限，不改业务代码绕过错误。复用：先识别连接边界，再改代码；不可把环境拒绝写成业务故障。
